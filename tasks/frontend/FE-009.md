# FE-009 — Education management and borrower-policy views

## Task information

- Owner: Frontend
- Status: Completed
- Priority: P2

## Outcome

Provide a simple education workspace for authorized staff to manage education records and understand borrower policy values.

## Dependencies

- FE-008

## Interfaces and source of truth

- Consumes: education endpoints from BE-020 and policy data from BE-021.
- Produces: education routes for people, academic records and read-only policy explanation.

## In scope

- Add grouped forms for student/teacher and academic relationships, splitting fields into logical sections.
- Render configured borrower policy values and their effect in plain language.
- Respect edition-disabled API responses with an explanatory unavailable state.

## Out of scope

- Client-side eligibility calculation, core circulation branching, public-library data and ungrouped long forms.

## Test-first sequence

1. Add frontend/tests/features/education/education-workspace.test.tsx for grouped form labels, policy display and edition-unavailable state.
2. Run: cd frontend; npm run test -- --run tests/features/education/education-workspace.test.tsx. Record the missing education-screen failure.
3. Implement education routes and typed form interactions.
4. Run the focused test, npm run typecheck, npm run lint and npm run build.
