# FE-007 — Circulation desk for request, approval, checkout and return

## Task information

- Owner: Frontend
- Status: Completed
- Priority: P2

## Outcome

Let authorized staff complete the core circulation lifecycle through a clear, low-step desk workflow.

## Dependencies

- FE-006

## Interfaces and source of truth

- Consumes: loan endpoints from BE-016 and idempotency behavior from BE-017.
- Produces: circulation route, request/approval/checkout/return actions and operation-result view.

## In scope

- Present current loan state and only the next server-permitted action.
- Support self-service request and staff approval/checkout/return flows.
- Handle repeat submission, conflict and domain failures through typed API responses.

## Out of scope

- Reservation queue management, money collection, policy calculation and multiple competing lifecycle actions.
