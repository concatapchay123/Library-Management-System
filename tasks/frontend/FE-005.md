# FE-005 — Catalog search and book browsing

## Task information

- Owner: Frontend
- Status: Completed
- Priority: P2

## Outcome

Enable users to find and inspect bibliographic books through a simple, typed catalog experience.

## Dependencies

- FE-004

## Interfaces and source of truth

- Consumes: book endpoints and cursor rules from BE-012 and the typed client from FE-004.
- Produces: catalog search route, book list, book detail and cursor-pagination controls.

## In scope

- Add one prominent search action with documented supported filter inputs.
- Render clear result summaries, empty state, loading state and recoverable error state.
- Add book detail views without exposing data from unavailable editions or tenant boundaries.

## Out of scope

- Copy mutation, inventory status changes, client-side search SQL, recommendation features and advanced saved search.
