# BE-012 — Bibliographic book catalog

## Task information

- Owner: Backend
- Status: Completed
- Priority: P1

## Outcome

Manage tenant-scoped bibliographic book records through a contract-first catalog API.

## Dependencies

- BE-006
- BE-011

## Interfaces and source of truth

- Consumes: authorization service from BE-010 and catalog conventions in docs/api-design.md.
- Produces: core.books, book repository/service and /books list/create/update endpoints.

## In scope

- Migrate books with tenant constraints, RLS policies and tenant-first indexes.
- Implement create, update, cursor listing and allow-listed catalog filtering.
- Enforce catalog permissions and stable validation/domain Problem Details.

## Out of scope

- Physical copies, locations, barcode handling, inventory status and frontend catalog UI.

## Test-first sequence

1. Add backend/tests/api/core/test_books.py for tenant isolation, allowed filters and cursor stability.
2. Run: cd backend; python -m pytest tests/api/core/test_books.py -q. Record the missing catalog-service failure.
3. Implement the book migration, repository, application service, OpenAPI contract and API adapters.
4. Run the focused API test and tenant catalog check.

## Evidence checkpoint

- A tenant cannot list or retrieve another tenant's books.
- Unsupported sort/filter fields are rejected before SQL construction.
