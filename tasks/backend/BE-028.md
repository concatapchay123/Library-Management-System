# BE-028 — Production configuration, clean-host deploy, backup and rollback rehearsal

## Task information

- Owner: Backend
- Status: Completed
- Priority: P1 release gate

## Outcome

Deploy the verified product to a clean host using secure runtime configuration and prove backup/restore and rollback behavior.

## Dependencies

- BE-027

## Interfaces and source of truth

- Consumes: release evidence from BE-027 and docs/deployment.md.
- Produces: production Compose profile, migration job, release runbook, restore runbook and rollback evidence.

## In scope

- Add immutable image tags, required-secret validation, network restrictions, Nginx TLS/security headers and SPA/API routing.
- Run migrations once through a readiness-gated job using migration-only database identity.
- Execute clean-host deployment, isolated restore and rollback-or-forward-fix rehearsal.

## Out of scope

- New business behavior, production secrets in source, public database/Redis access and unsupported backward-incompatible migration rollback.

## Test-first sequence

2. Run: powershell -ExecutionPolicy Bypass -File infra/tests/test_production_release.ps1. Record the missing production-profile failure.
3. Implement production configuration, migration job and operational runbooks.
4. Run the production smoke test, clean-host deploy, backup/restore and rollback rehearsal commands.
