# BE-025 — In-app notification persistence and read workflow

## Task information

- Owner: Backend
- Status: Completed
- Priority: P2

## Outcome

Persist tenant-scoped in-app notifications from durable domain events and let authorized users read or mark them read.

## Dependencies

- BE-024
- BE-015

## Interfaces and source of truth

- Consumes: durable dispatcher from BE-015 and event-producing circulation/payment workflows.
- Produces: core.notifications, notification consumer and notification read API.

## In scope

- Migrate notification records with delivery/read state and tenant constraints.
- Consume versioned loan, reservation, overdue and payment events idempotently.
- Implement notification listing and read-state mutation with authorization.

## Out of scope

- Email provider delivery, UI inbox, push notifications and a second outbox protocol.
