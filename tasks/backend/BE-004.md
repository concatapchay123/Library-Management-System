## Task information

- Owner: Backend
- Status: Completed
- Priority: P0

## Outcome

Create the fail-closed organization registry and the narrow database boundary required to resolve a login tenant before authenticated context exists.

- Implement the narrowly granted security-definer login resolver and deny direct pre-context registry reads.

## Out of scope
