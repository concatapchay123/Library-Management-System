# BE-027 — Full integration, security and release-evidence verification

## Task information

- Owner: Backend
- Status: Planned
- Priority: P1 release gate

## Outcome

Produce fresh, reproducible evidence that the completed backend and frontend satisfy integration, security, accessibility, performance and compatibility gates.

## Dependencies

- BE-026
- FE-010

## Interfaces and source of truth

- Consumes: all active capability tasks, docs/testing-strategy.md and docs/security.md.
- Produces: release-evidence record, automated gate coverage and documented known limits.

## In scope

- Run and complete the full backend, SQL Server, frontend, OpenAPI, Compose, dependency and secret checks.
- Add missing high-risk cases for RLS catalog/composite FKs, token reuse, audit/outbox atomicity, dispatcher replay, payment replay and idempotency retention.
- Measure reproducible catalog-search and checkout baselines.
- Run accessibility checks against the implemented frontend and record release evidence.

## Out of scope

- Production deployment, changing release thresholds to pass, new product capability and performance tuning without measured evidence.

## Test-first sequence

1. Add backend/tests/integration/release/test_release_gate.py for any missing critical gate identified by the matrix.
2. Run the focused release-gate test and record its expected failure before adding the minimum missing coverage.
3. Implement only missing checks or fixes required for the failed gate.
4. Run the complete documented release command matrix from a clean checkout.

## Evidence checkpoint

- Every Phase 0 through Phase 9 requirement points to fresh command output.
- No critical or high dependency, security or delegated-review finding remains open.

## Acceptance criteria

- Full CI is green from a clean checkout.
- SQL Server backup/restore drill and retention/legal-hold checks have documented evidence.
- Frontend has zero critical or serious accessibility violations in tested critical flows.

## Reviewer checklist

- No test is skipped, weakened or deleted to make a gate pass.
- Performance results include environment and data volume.
