### 2. Evidence Checkpoint Validation
- **An inactive subscription cannot provide a borrowing policy:**
  - Validated by `test_inactive_subscription_cannot_provide_borrowing_policy`:
    When a subscription is cancelled, expired (`ends_at <= now`), or future (`starts_at > now`), calling `resolve_policy` raises `BorrowerNotEligibleError`.
  - Also validated that a member whose profile status is suspended/inactive cannot borrow even with an active subscription (`test_inactive_member_cannot_provide_borrowing_policy`).
- **Plan defaults are tenant-scoped seed data, not controller constants:**
  - Validated by `test_plan_defaults_are_tenant_scoped_seed_data`:
    Default plans Basic (5 books / 30 days) and Premium (20 books / 90 days) are seeded into `public_library.membership_plans` using SQL Server `MERGE` without overwriting tenant customizations.
    Modifying the plan in the database (e.g. from 5 to 8 books, 30 to 45 days) takes immediate effect in future policy resolutions without requiring code or controller changes.
- **Snapshot fields are validated and immutable after checkout:**
  - Validated by `test_plan_changes_do_not_mutate_loan_policy_snapshot`:
    Checked-out loans capture `borrower_type`, `max_active_loans`, `duration_days`, `due_at`, and subscription/plan identifiers in `policy_snapshot`. Updating the underlying membership plan afterwards does not mutate existing loan due dates or snapshot facts.
- **Core circulation dependency isolation (Zero Public Library Imports):**
  - Validated by `test_zero_public_library_imports_in_core`:
    Inspects Python AST across all modules in `openlibrary.modules.core` and verifies 0 imports or references to `openlibrary.modules.public_library`.

### 3. Architecture & Separation of Concerns
- **Core Port Integration:**
  - `PublicLibraryBorrowingPolicyAdapter` implements the `BorrowingPolicyResolver` protocol consumed by core circulation.
  - Runtime chains `PublicLibraryBorrowingPolicyAdapter` -> `EducationBorrowerPolicyAdapter` -> `DefaultBorrowingPolicyResolver`.
- **Public Library Module (`openlibrary.modules.public_library`):**
  - `domain.py`: Immutable dataclasses `Member`, `MembershipPlan`, `Subscription` with domain validation helpers and typed exceptions.
  - `application.py`: `PublicLibraryStore` persistence port and `PublicLibraryService` application use cases enforcing edition enablement and RBAC permissions (`public_library.read`, `public_library.manage`).
  - `policy.py`: `PublicLibraryBorrowingPolicyAdapter` resolving tenant-scoped borrowing policy rules from active subscriptions.
  - `infrastructure.py`: `SqlServerPublicLibraryStore` using SQLAlchemy 2.x parameterized queries, tenant connection RLS context, and seed MERGE logic.
  - `api.py`: Blueprint providing REST endpoints for `/members`, `/membership-plans` (with `/plans` alias), and `/subscriptions`, converting domain exceptions to RFC 7807 problem details.
- **Database Migration:**
  - `0016_public_library_memberships.py`: Creates `public_library.membership_plans`, `public_library.members`, and `public_library.subscriptions` with composite tenant keys, foreign keys to `core.organizations` and `core.users`, and RLS filter/block predicates attached to `core.organization_tenant_policy`.
