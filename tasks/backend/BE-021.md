# BE-021 — Education borrower-policy adapter and loan snapshots

## Task information

- Owner: Backend
- Status: Completed
- Priority: P2

## Outcome

Resolve configurable education borrowing policies through a stable port and snapshot the selected policy at checkout.

## Dependencies

- BE-020
- BE-016

## Interfaces and source of truth

- Consumes: education profiles from BE-020 and core policy port consumed by BE-016.
- Produces: education policy resolver, seed policy data and checkout policy snapshot integration.

## In scope

- Add configurable organization policy data for student default 5 books/14 days and teacher default 20 books/90 days.
- Resolve policy through the core port without importing education code into core domain entities.
- Store selected policy facts on the loan at checkout.

## Out of scope

- Public membership policy, fines, frontend configuration forms and controller-level hard-coded limits.

## Test-first sequence

1. Add backend/tests/integration/education/test_policy_adapter.py for student/teacher resolution, override and checkout snapshot.
2. Run: cd backend; python -m pytest tests/integration/education/test_policy_adapter.py -q. Record the missing policy-adapter failure.
3. Implement policy data, resolver adapter and checkout integration.
4. Run the focused integration test and core loan API test.

## Evidence checkpoint

- Changing an organization policy affects future eligibility without controller changes.
- Existing loan due date and limit facts remain stable after policy changes.

## Acceptance criteria

- Education defaults are seed/configuration data.
- Core circulation depends only on its policy interface.
- Student and teacher policy selection remains tenant scoped.

## Reviewer checklist

- [x] No education conditional branch is added to core loan entities.
- [x] Snapshot fields are validated and immutable after checkout.

### 3. Architecture & Separation of Concerns
- **Core Port:**
  - Declared `BorrowingPolicy` dataclass, `BorrowingPolicyResolver` protocol, and `DefaultBorrowingPolicyResolver` in `openlibrary.modules.core.application.loans`.
  - Added `BorrowerNotEligibleError` to `openlibrary.modules.core.domain.loans`.
  - Updated `LoanService` to accept optional `BorrowingPolicyResolver` (defaulting to `DefaultBorrowingPolicyResolver`) and snapshot policy facts during `request_loan` and `checkout_loan`.
  - Updated RFC 7807 handler in `openlibrary.modules.core.api.loans` for `BorrowerNotEligibleError` (HTTP 422).
- **Education Adapter & Application:**
  - Created `openlibrary.modules.education.policy.EducationBorrowerPolicyAdapter` implementing `BorrowingPolicyResolver`.
  - Resolves borrower profile as student or teacher (raising `BorrowerNotEligibleError` if neither is found).
  - Retrieves tenant policy override from `education.borrower_policies` via `EducationStore`, falling back to `DEFAULT_EDUCATION_POLICIES` (Student: 5 books / 14 days; Teacher: 20 books / 90 days).
  - Extended `EducationStore` and `SqlServerEducationStore` with `get_student_by_user_id`, `get_teacher_by_user_id`, `get_borrower_policy`, `list_borrower_policies`, and `upsert_borrower_policy` (using SQL Server `MERGE`).
  - Added API endpoints in `openlibrary.modules.education.api` for `GET /borrower-policies`, `GET /borrower-policies/<borrower_type>`, and `PUT /borrower-policies/<borrower_type>`.
  - Wired `EducationBorrowerPolicyAdapter` into `LoanService` in `openlibrary.app.runtime`.
