# BE-013 — Locations and individually tracked copies

## Task information

- Owner: Backend
- Status: Completed
- Priority: P1

## Outcome

Register tenant-scoped locations and physical copies, including barcode uniqueness and copy condition.

## Dependencies

- BE-012

## Interfaces and source of truth

- Consumes: book catalog from BE-012 and inventory permission definitions in docs/api-design.md.
- Produces: core.locations, core.book_copies and location/copy API resources.

## In scope

- Migrate locations and copies with tenant composite constraints, RLS and barcode indexes.
- Implement copy registration, condition updates and location assignment.
- Expose permission-protected API contracts for locations and copies.

## Out of scope

- Copy status transitions, loans, reservations and frontend inventory workspace.

## Test-first sequence

1. Add backend/tests/api/core/test_inventory.py for duplicate tenant barcode, location isolation and multiple copies per book.
2. Run: cd backend; python -m pytest tests/api/core/test_inventory.py -q. Record the missing copy/location failure.
3. Implement migrations, services, contracts and API adapters.
4. Run the focused API test and tenant migration catalog check.

## Evidence checkpoint

- Barcode duplication is rejected within an organization and allowed across organizations.
- One bibliographic book can own multiple physical copies.
