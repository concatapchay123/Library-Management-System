# BE-001 App Factory and Health Endpoints Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create the deterministic Flask entry point and health endpoints required by BE-001.

**Architecture:** `AppConfig` injects a readiness probe into `create_app`, so the factory has no import-time I/O and BE-002 can later provide SQL Server and Redis checks. The `/api/v1/health` blueprint keeps HTTP adaptation thin: liveness is process-only, while an unavailable probe produces a sanitized RFC Problem Details response.

**Tech Stack:** Python 3.11+, Flask, pytest, Ruff, mypy.

**Spec:** `tasks/backend/BE-001.md`

## Global Constraints

- `create_app(config)` is the only application entry point; importing modules must create no network connection, credential, or mutable request state.
- All API routes are under `/api/v1`; the deployment health-endpoint documentation must match that canonical prefix.
- The live endpoint must not invoke the readiness probe or access SQL Server or Redis.
- Readiness failure is a stable RFC Problem Details response with no stack trace, secret, or dependency detail.
- No database, authentication, non-health route, Docker, migration, or OpenAPI work is included.

### Task 1: Define the factory behavior with a failing test

**Files:**

**Interfaces:**
- Consumes: the BE-001 endpoint contract.
- Produces: executable behavioral expectations for `AppConfig`, `create_app`, and both health routes.

- [x] **Step 1: Write the failing test**

```python
from openlibrary.app.config import AppConfig
from openlibrary.app.factory import create_app


def test_factory_exposes_live_health_without_using_readiness_probe() -> None:
    def unavailable() -> bool:
        raise AssertionError("liveness must not call the readiness probe")

    app = create_app(AppConfig(readiness_probe=unavailable))
    response = app.test_client().get("/api/v1/health/live")

    assert response.status_code == 200
    assert response.get_json() == {"status": "ok"}


def test_readiness_returns_problem_details_when_dependency_is_unavailable() -> None:
    app = create_app(AppConfig(readiness_probe=lambda: False))
    response = app.test_client().get("/api/v1/health/ready")

    assert response.status_code == 503
    assert response.content_type == "application/problem+json"
    assert response.get_json() == {
        "type": "https://openlibraryos.example/problems/dependency-unavailable",
        "title": "Service unavailable",
        "status": 503,
        "detail": "A required dependency is unavailable.",
        "instance": "/api/v1/health/ready",
    }
```

- [x] **Step 2: Implement the config, health blueprint, and factory**

```python
@dataclass(frozen=True)
class AppConfig:
    readiness_probe: ReadinessProbe


def create_app(config: AppConfig) -> Flask:
    app = Flask(__name__)
    app.register_blueprint(create_health_blueprint(config.readiness_probe))
    return app
```

The live view returns `{\"status\": \"ok\"}` without invoking the probe. The ready view calls the probe once; a false result returns the exact 503 Problem Details body from Task 1. Concrete probes added in BE-002 must convert dependency errors to `False`.
