# OpenLibraryOS

OpenLibraryOS là nền tảng vận hành thư viện mã nguồn mở, multi-tenant và modular. Phiên bản đầu tiên ưu tiên một backend Flask modular monolith, một React frontend và SQL Server với tenant isolation ở database layer.
